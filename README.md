## 数据集摘要
本数据集为高清糖尿病视网膜病变眼底医学数据集，图像尺寸1280×1280，同时支持**分级分类、病灶目标检测、病灶语义分割**三大任务。包含1820+张眼底原图、7576张像素级分割mask；检测子集共1737张图、78906个标注框，覆盖6种视网膜病灶；分类子集按病变严重程度分为5级，样本分布不均衡，重度样本数量多、正常样本偏少。标注同时提供YOLO检测标签与分割mask，适配YOLO系列检测模型、UNet、DeepLabv3+、SegFormer等主流分割网络，适合医学影像AI相关研究与产品开发。

## 应用场景
- 糖尿病视网膜病变自动筛查与分级系统开发
- 眼底病灶检测、分割方向论文实验
- 医学影像AI竞赛（Kaggle DR类赛事）
- 眼科AI辅助诊断产品研发
- 深度学习课程作业、本科/硕士毕设

## 应用价值
1. **多任务一体化**：一套数据集同时支持分类、检测、分割，一套数据可做多方向医学影像实验；
2. **分辨率高清**：1280×1280高清眼底图，微小病灶特征保留完整，利于细粒度病灶识别；
3. **病灶覆盖全面**：包含6类典型DR病灶，贴合临床医生诊断关注目标；
4. **格式友好**：YOLO检测标注+像素mask，开箱适配主流检测、分割框架；
5. **天然类别不平衡**：贴近真实临床数据分布，适合研究医学场景下的类别不平衡、长尾学习方案。
